# 🍣 日料店经营分析助手

日料店日常经营数据分析诊断工具，帮助店主快速了解每日/每周经营状况。

## 功能特性

- 📊 **营收分析** - 日/周/月营收趋势、同比/环比变化
- 📈 **对比分析** - 本期 vs 上期，变化率可视化
- 🍣 **菜品分析** - 热销 TOP10、滞销预警、毛利贡献
- ⏰ **时段分析** - 午市/晚市占比、高峰时段识别
- 🪑 **桌台效率** - 翻台率、包间使用率、座位利用率
- 📅 **每日趋势** - 多日数据连成趋势线
- 📈 **可视化图表** - 营收趋势、热销排行、分类占比等
- 🔍 **数据验证** - 自动检查数据完整性

## 快速开始

### 1. 初始化（首次使用）

```
/sushi-analysis setup
```

Skill 会自动创建以下文件夹结构：

```
~/sushi-data/
├── reference/                       # 基础数据（固定）
│   ├── dishes.xlsx                  # 菜品目录
│   └── tables.xlsx                  # 桌台信息
├── 2026-01/                        # 月度销售数据
│   └── sales_2026-01-08.xlsx
└── reports/                         # 分析报告输出
```

### 2. 数据准备

#### 销售日报 (`sales_YYYY-MM-DD.xlsx`)

| 列名 | 说明 | 示例 |
|------|------|------|
| 订单号 | 唯一订单标识 | SO-20260108-001 |
| 时间 | 下单时间 | 12:30 |
| 桌台 | 桌台号 | A1、VIP-1 |
| 菜品名称 | 菜品名 | 三文鱼刺身 |
| 分类 | 菜品分类 | 刺身、寿司、烧物 |
| 数量 | 销售数量 | 2 |
| 单价 | 单价(元) | 68.00 |
| 金额 | 小计(元) | 136.00 |
| 支付方式 | 支付渠道 | 微信、支付宝、现金、刷卡 |

#### 菜品目录 (`dishes.xlsx`)

| 列名 | 说明 | 示例 |
|------|------|------|
| 菜品名称 | 菜品名 | 三文鱼刺身 |
| 分类 | 菜品分类 | 刺身 |
| 成本 | 成本(元) | 28.00 |
| 售价 | 售价(元) | 68.00 |

#### 桌台信息 (`tables.xlsx`)

| 列名 | 说明 | 示例 |
|------|------|------|
| 桌台号 | 桌台标识 | A1、VIP-1 |
| 座位数 | 座位数量 | 4 |
| 区域 | 区域分类 | 大厅、包间 |
| 是否包间 | 是否VIP包间 | 是、否 |

### 3. 运行分析

```
/sushi-analysis analyze [选项]
```

可选分析类型：
- `today` - 今日日报
- `week` - 本周分析（含同比）
- `range YYYY-MM-DD YYYY-MM-DD` - 指定日期范围（含环比）
- `all` - 全部数据汇总

## 新增功能 (v1.1.0)

### 同比/环比对比
- 本周 vs 上周自动对比
- 指定期间与上一期间对比
- 营收、订单数变化率

### 数据验证
- 自动检查必需列是否完整
- 识别空行和异常数据
- 生成验证报告

### 滞销预警
- 自动识别销量低的菜品
- 提示需要关注的滞销品

### 每日趋势图
- 多日数据连成趋势线
- 按日期查看营收变化

## 输出报告

支持多种格式输出：
- 📝 文字摘要 - 关键指标一览
- 📊 Markdown 报告 - 含图表
- 🌐 HTML 网页 - 可保存分享

报告自动保存到 `~/sushi-data/reports/` 目录

## 数据维护

- **每日**：更新 `sales_YYYY-MM-DD.xlsx`
- **菜品变动**：更新 `reference/dishes.xlsx`
- **桌台变动**：更新 `reference/tables.xlsx`

## 技术栈

- Python 3.8+
- pandas - 数据处理
- matplotlib - 图表生成
- openpyxl - Excel 读取
